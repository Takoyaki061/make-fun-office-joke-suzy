## The joke

> I marked an email as unread so I could experience the thrill of ignoring it twice.

`main.py` (Python 3.13, stdlib only) writes this one-line joke to `entry.txt`
in the output directory (`MAKEFUN_OUTPUT` env var, or `/output` by default).
